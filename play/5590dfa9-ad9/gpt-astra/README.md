# Cosmic Goo

A browser slime toy for science night, built with HTML, CSS, and Canvas. No installation or build step required.

Open `index.html` directly, or run `npm start` and visit http://localhost:3000.

- Drag the slime to stretch it; release to watch it spring back.
- Press **S** to squish and reunite it, or **D** to split it into two draggable blobs.
- Choose a color, adjust firmness, or toggle the stardust.
- Use the top-right full-screen button for the stall and **Start fresh** between turns.

The toy works offline; the optional Google Fonts fall back to system fonts. The slime is a playful spring simulation, not a scientific model of a non-Newtonian fluid.
