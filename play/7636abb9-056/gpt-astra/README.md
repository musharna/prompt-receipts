# Little world — Terrarium studio

An interactive 3D birthday terrarium with a transparent glass jar, layered substrate, moss, fern fronds, and a ceramic deer.

Run `npm run dev`, then open http://localhost:5173. Python 3 and Node.js are required; no package installation is needed. Run `npm run build` to create the static site in `dist/`.

Drag to orbit, scroll or pinch to zoom, and use the view buttons for automatic rotation or a top view. Adjust moss, fern count, and deer position in the sidebar. Save a PNG snapshot or download your design notes from the Build notes tab.

Three.js is bundled locally under its MIT license in `vendor/THREE-LICENSE.txt`. The optional Google Fonts stylesheet falls back to installed fonts when offline. Jar dimensions and planting quantities are illustrative planning estimates.
