# Mochi — desktop axolotl

A small, cozy desktop companion that wanders along the taskbar and curls up when your mouse is idle.

## Run it

Open `index.html` directly, or run the tiny local server:

```bash
npm start
```

Then visit <http://localhost:4173>.

In Chrome or Edge, use the install icon in the address bar to keep Mochi as a standalone desktop app. It continues to work offline after the first visit.

Move the pointer near the lower half of the screen and Mochi will follow. Leave the pointer alone and Mochi will nap. The settings button lets you adjust the idle time or turn pointer-following off.
