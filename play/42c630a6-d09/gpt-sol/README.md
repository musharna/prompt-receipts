# Fold Lab

An interactive, printable origami resource for five club models: crane, jumping frog, sailboat, swan, and waterbomb.

Open `index.html` directly in a browser, or serve the folder locally:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

Each model includes a six-step player, previous/next controls, a finished-model crease map, and an SVG download. “Print patterns” creates one crease pattern per page.
