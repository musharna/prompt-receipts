# Prompt Receipts

Prompts for making things with Claude Code, each run once on plain Claude Code (Opus, Sonnet, Haiku) and GPT via Codex, with what came out, what it cost and how long it took.

Site: https://musharna.github.io/prompt-receipts/

Tried one? Use the "Tell us how it went" button on its card. Runs that didn't work are as useful as ones that did.
