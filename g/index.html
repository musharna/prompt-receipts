    To show how you made something, run receipt.py --prompt --turns --recipe --redact --share in the folder you worked in. The receipt lists each prompt you sent, with its time, cost and what it did, and the commands to run them again; email addresses and keys are blanked out. --turns 3-5 covers only prompts 3 to 5. --share opens a GitHub issue with the link filled in, where you can say whether it worked and what it made, or paste a link from --link here. A bot replies with what the gallery will show, and it goes in once the site's owner approves it. Everything in it is public, so read it first. A receipt can be edited, so sent-in ones are shown as sent.
